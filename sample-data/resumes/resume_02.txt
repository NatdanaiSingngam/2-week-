สนใจพัฒนาระบบหลังบ้านด้วยภาษา Python เคยใช้ Django กับ Flask สร้างเว็บขายของมือสองในรายวิชาโครงงาน เก็บข้อมูลใน PostgreSQL และใช้ Linux เป็นเซิร์ฟเวอร์ทดสอบ ฝึกใช้ Docker เบื้องต้น และศึกษา AWS ในส่วนของเซิร์ฟเวอร์เสมือน ปิดเทอมที่ผ่านมาไปเที่ยว Java Island กับครอบครัว ชอบแก้ปัญหาที่ซับซ้อน มีทักษะการแก้ปัญหาจากการแข่งขันเขียนโปรแกรม
