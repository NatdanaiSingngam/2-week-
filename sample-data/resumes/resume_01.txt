ผมเป็นนักศึกษาปี 4 สาขาวิทยาการคอมพิวเตอร์ สนใจงานฝั่งเซิร์ฟเวอร์ เคยทำระบบจองห้องประชุมด้วย Spring Boot และ MySQL เขียน REST API ให้ฝั่งหน้าเว็บเรียกใช้ ใช้ Git และ GitHub ทำงานร่วมกับเพื่อนในทีม 3 คน ทดสอบ API ด้วย Postman และใช้ Docker รันฐานข้อมูลในเครื่อง มีพื้นฐาน Java และ SQL ที่แข็งแรง ทำงานเป็นทีมได้ดี และรับผิดชอบงานที่ได้รับมอบหมายจนเสร็จ
